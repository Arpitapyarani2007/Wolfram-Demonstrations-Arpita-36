Introduction :

This project explores mathematical concepts through interactive simulations using Wolfram Demonstrations. The experiments involved changing simulation controls, observing graphs, and understanding mathematical results.
Experiments Performed

1. An Algorithm to Compute Square Roots of Integers -

Objective: To understand how algorithms calculate square roots through repeated steps.

Learning Outcome: Learned how iterative calculations help approximate square roots.

2. Continuous Functions Are Integrable -
   
Objective: To understand Riemann sums and area approximation using rectangles.

Learning Outcome: Understood how upper and lower sums approximate the area under a curve and help explain definite integration.

3. Half-Life of a Radioactive Element -
   
Objective: To study radioactive decay and the concept of half-life.

Learning Outcome: Understood how radioactive substances decay over time and how their half-life values differ.

4. Chi-Squared Distribution and the Central Limit Theorem -
   
Objective: To explore chi-squared and normal distributions.

Learning Outcome: Understood probability density functions (PDF), cumulative distribution functions (CDF), and the relationship between chi-squared and normal distributions.
